Refractgithub.com/OsamaAnsar/refract-rag

A hybrid RAG system that shows its work: from-scratch BM25 (lexical) and HNSW (vector) retrieval run in parallel and get fused with Reciprocal Rank Fusion, with multi-hop agentic decomposition for cross-topic questions. The UI visualizes every retrieval score, fusion rank, and sub-question live as it runs.

LLM-judge evaluation harness for RAG pipelines — faithfulness, answer relevance, context precision, and context recall — with a CI regression gate that catches planted hallucinations in a benchmark dataset. Pluggable Judge interface (real OpenAI judge plus a dependency-free FakeJudge for CI).

Multi-hop agentic RAG pipeline: decomposes complex questions into sub-questions, retrieves evidence with a from-scratch BM25 implementation, checks answer sufficiency, and synthesizes a cited final answer.
